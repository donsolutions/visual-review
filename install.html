Visual Review

A bookmarklet that adds a Pastel-style annotation overlay to any webpage. Drop comments, edit text, draw, drag sections, add elements — export everything as markdown for an AI coding assistant.

Install in one second

Drag this button to your bookmarks bar.

📝 Visual Review
Drag → drop on the bookmarks bar. If you don't see your bookmarks bar, press Cmd+Shift+B (Mac) or Ctrl+Shift+B (Windows/Linux).

How to use

  1. Visit any page you want to review — your own landing page, a partner's site, a competitor, anything.
  2. Click the bookmark in your bookmarks bar. The toolbar appears in the bottom-right corner.
  3. Annotate. Pin comments, edit text, draw, drag sections, add new elements.
  4. 📤 Send in the toolbar. The export — a structured markdown blob with stable CSS selectors for every annotation — copies to your clipboard.
  5. Paste it into Claude, ChatGPT, Cursor, or hand it to a developer. The format is designed for an AI assistant to apply every change without screenshots.

What you get

📌 Pin comments

Click any element, drop a numbered pin with a note.

✏️ Edit text inline

Bold, italic, underline, links. Before/after diff captured.

✍️ Draw on the page

Freehand pen, five colors. Strokes anchor to sections.

↕ Move and delete

Drag sections to reorder. Mark sections for deletion.

➕ Add elements

Drag headlines, buttons, images, testimonials onto the page.

📤 Export

Markdown + JSON with CSS selectors for every change.

If the bookmarklet doesn't load

Some sites use Content Security Policy to block external scripts. If the bookmark click does nothing, open DevTools → Console. If you see a CSP error, use this fallback:

  1. DevTools → Sources → Snippets → New snippet
  2. Paste the contents of review.js
  3. Right-click → Run (or Cmd/Ctrl+Enter)
  4. Then paste the CSS via Console:
    var s=document.createElement('style');s.textContent=`/* paste review.css */`;document.head.appendChild(s);
