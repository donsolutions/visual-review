Get started

Three quick things

Drop-in script. No dependencies. Annotations export as markdown.

1

Pin and edit

Click any element to leave a pinned comment. Click any text to edit it inline. The export captures a before/after diff with a CSS selector.

2

Draw on the page

Freehand pen with five colors. Strokes anchor to the section they live in, so they reposition correctly on scroll and reload.

3

Move and add

Drag sections to reorder. Mark sections for deletion. Drag elements from the palette to insert new content between existing siblings.
